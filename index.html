Adding a demo

  1. Start a cloud session on this repo and describe the demo you want.
  2. Claude builds it in its own folder on the session’s branch, adds a row to this page and opens a pull request into main.
  3. Merge the pull request. GitHub Pages republishes in about a minute, at /RemoteFunLand/<folder>/.

The conventions every new demo follows are in CLAUDE.md at the root of the repo.
